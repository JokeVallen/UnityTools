## 六、调度方式选择指南

### 6.1 串行调度适用场景

| 场景 | 原因 | 推荐版本 |
|------|------|---------|
| 内存受限环境 | 分配少 20-25% | UniTask / ValueTask |
| CPU 密集计算 | 避免任务调度开销 | Task |
| 依赖链长、并行度低 | 串行更高效 | 任意 |
| 低频调用 | 分配差异可忽略 | 任意 |

### 6.2 并行调度适用场景

| 场景 | 原因 | 推荐版本 |
|------|------|---------|
| IO 密集 | 网络/磁盘等待可并行 | Task |
| 高吞吐量 | 并发执行提升效率 | Task / UniTask |
| 并行度高的 DAG | 多个无依赖步骤 | 任意 |
| Unity 游戏逻辑 | 利用 UniTask 低分配 | UniTask |

## 八、关键结论

| 结论 | 说明 |
|------|------|
| **UniTask 内存最优** | 串行 65.7 KB，并行 85.2 KB (Unity Mono 环境) |
| **ValueTask 串行专用** | 115.4 KB，不支持并行 |
| **Task 功能最全** | 支持串行+并行，139.5-176.8 KB |
| **串行比并行省内存** | 节省 20-25%，适合内存敏感场景 |
| **并行比串行更适合 IO** | 耗时相近，但吞吐更高 |
