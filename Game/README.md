# 游戏开发库

[![MIT License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

## 列表

- [SkillFramework](./SkillFramework/README.md)  
    一个专为高性能游戏设计的、纯 C# 实现的轻量级战斗逻辑核心底座。该库聚焦于解决游戏战斗系统中动态属性膨胀、解耦带来的虚函数开销、高频混战引发的 GC 压力、Buff 生命周期的时序安全（防爆） 以及 实体的强内聚组件组装 等核心痛点。它不依赖于任何特定的游戏引擎（如 Unity），天然支持 Client / Server 同源架构。
